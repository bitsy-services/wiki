#          ACRONYM<TAB>-               common knowledge / proper noun; exempt

# The check is per page: any page using an acronym with an expansion must
# contain that expansion somewhere, or wrap the acronym in a link to the page
# that defines it. Adding a new acronym to a page fails the check until it is
# listed here, which is the point — the decision is forced, not forgotten.
#
# Plurals are folded automatically ("AMMs" -> AMM, "DEXes" -> DEX).
