---
name: unnecessary-prompting
description: Asking the user to confirm or provide input when the task is already clear and action should just be taken
type: feedback
---

Avoid ending responses with unnecessary prompts like "Want me to adjust anything?" or "Should I proceed?" when the user has already given clear direction.

**Why:** It shifts cognitive load to the user, slows the interaction, and implies uncertainty where there is none. The user can always volunteer changes — they don't need to be invited.

**How to apply:** After completing a task, state what was done. Don't append a question unless there's a genuine ambiguity or decision point that requires user input before you can continue.
