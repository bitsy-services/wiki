An agentic workflow is a language model running in a loop with tools — planning, acting, observing the result, and deciding the next step — rather than answering in a single call. This page will cover when an agent is worth the overhead versus a single structured call, planning and decomposition, tool design, sub-agent delegation (a key lever for [context engineering](/wiki/ai/context-engineering)), and verification loops that catch the model's own mistakes.
